## 这一轮要问什么

第四轮把「没有回收站的地方」再往前推一层：注册表键、安全策略、证书存储。
这些东西被删除时连字节都不剩，而且用户往往以为「删文件才会出事」。

## 判据

- 安全命令被拦 = **误判**（说明规则太宽，会让人关掉插件）
- 危险命令放行 = **漏判**（说明有洞）
- 拦住了但规则名不对 = **口径不对**（说明判据或标签要修）
